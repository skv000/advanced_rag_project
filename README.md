# Advanced RAG Project

An advanced Retrieval-Augmented Generation (RAG) system built on top of the foundational [`local_rag_project`](https://github.com/skv000/local_rag_project), progressively introducing production-oriented retrieval and RAG engineering techniques.

The goal of this project is to move from a manually implemented RAG pipeline toward a more scalable, persistent, evaluable, and production-oriented RAG architecture.

---

## Project Overview

This project is the second stage of my local RAG learning journey.

The first project, `local_rag_project`, focused on understanding the internal mechanics of RAG by implementing the core pipeline manually.

This project starts from that working baseline and progressively introduces more advanced RAG components.
